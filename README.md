## 🔐 نظام الأمان والصلاحيات (Role-Based Access Control - RBAC)

تم تزويد المنصة بنظام أمني متكامل يفصل بين مستويين من الوصول:

### 1. عامة الطلبة والزوار (Public Visitors / Students)
- **بدون تسجيل دخول إطلاقاً (No Login Required)**.
- صلاحيات قراءة فقط (Public Read) لجميع المراحل الـ 4، الفصول الـ 8، والمقررات الـ 52.
- قراءة ومعاينة ملفات PDF ومستندات الملازم وتحميلها.
- مشاهدة فيديوهات YouTube التعليمية المعتمدة داخل مشغل مدمج أو عبر يوتيوب.
- حجب كافة أزرار وإجراءات التعديل، الرفع، الحذف، وتغيير الصلاحيات عنهم تماماً.

### 2. إدارة القسم والأساتذة (Administrators)
- **تسجيل دخول آمن ومشفر عبر Supabase Auth** (البريد الإلكتروني + كلمة المرور).
- التحقق الصارم من رتبة المسؤول في جدول `public.administrators` المحمي بسياسات الأمان على مستوى الصفوف (Row Level Security - RLS).
- الدخول إلى لوحة التحكم الأكاديمية (`#/admin`).
- إضافة وتعديل وحذف المواد الدراسية.
- رفع واستبدال وحذف الملفات والمحاضرات وفيديوهات YouTube.
- التحقق من الهوية والصلاحية قبل كل عملية كتابة برمجياً وفي قاعدة البيانات.
- عدم تخزين أي كلمات مرور في الواجهة الأمامية أو `localStorage`.

## 🛠️ خطوات إعداد وربط قاعدة بيانات Supabase (للمسؤولين)

لتفعيل المزامنة السحابية والحفظ المركزي:

1. **إنشاء مشروع Supabase مجاني:**
   - ادخل إلى [supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً.

2. **تطبيق مخطط قاعدة البيانات وسياسات الأمان (RLS):**
   - افتح **SQL Editor** في لوحة تحكم Supabase.
   - انسخ محتويات ملف [`supabase_schema.sql`](file:///C:/Users/AHC/Downloads/simulation/supabase_schema.sql) بالكامل والصقها هناك واضغط **Run**.
   - سيقوم بإنشاء:
     - الجداول الخمسة: `academic_years`, `semesters`, `subjects`, `materials`, `administrators`.
     - سياسات الأمان (RLS) وحاويات التخزين السحابية `academic-materials` بحجم أقصى 50MB.
     - بيانات المقررات الأكاديمية الـ 52 كاملة.

3. **إنشاء حساب أول مدير نظام (Admin User):**
   - في Supabase، اذهب إلى: **Authentication** ⬅️ **Users** ⬅️ اضغط **Add user**.
   - أدخل بريد إلكتروني (مثال: `admin@pge-thiqar.edu.iq`) وكلمة مرور قوية.
   - انسخ **User UID** الخاص بهذا الحساب.
   - في **SQL Editor**، شغّل الاستعلام التالي لتسجيله كـ `super_admin`:
     ```sql
     INSERT INTO public.administrators (user_id, email, full_name, role)
     VALUES ('<ضع_هنا_User_UID>', 'admin@pge-thiqar.edu.iq', 'رئاسة قسم هندسة النفط والغاز', 'super_admin')
     ON CONFLICT (user_id) DO UPDATE SET role = 'super_admin';
     ```

4. **ربط الواجهة الأمامية (GitHub Pages):**
   - افتح الموقع ⬅️ اذهب إلى **دخول الإدارة** أو الإعدادات ⬅️ أدخل:
     - **Project URL:** `https://xyz.supabase.co`
     - **Anon Key:** `eyJhbGci...`
   - يتم تخزين المفتاح العام الآمن فقط محلياً، وتسجيل الدخول عبر بريدك الإلكتروني وكلمة المرور المشفرة.
